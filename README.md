# Frontend Design Samples

このリポジトリには、React + Vite のサンプルプロジェクトが含まれています。

## Projects

- `react/atomic-design-sample`
  - Atomic Design 構成の UI サンプル
- `react/local-storage-sample`
  - `localStorage` を使ったライブラリ CRUD サンプル

## Quick Start

各プロジェクトディレクトリで実行してください。

```bash
npm install
npm run dev
```
